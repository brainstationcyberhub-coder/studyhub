## 📖 Overview

**Study Hub** is a collaborative educational project built by students of **Dong-eui University, South Korea**. It gives beginners a simple, clutter-free space to explore learning materials, revisit topics whenever they need, and build technical skills at their own pace.

The platform covers everything from computer fundamentals to popular programming and web technologies.

## ✨ Features

- **Focused Learning**: a clean interface with no pop-ups or social media distractions
- **Easy Learning**: study at your own pace and revisit lessons any time
- **Practical Skills**: bridges theory and real-world application
- **Continuous Growth**: encourages small, consistent daily progress
- **Team Voices**: member profiles introducing each contributor
- **Feedback Form**: lets learners rate courses and share suggestions
- **Responsive-ready**: includes the viewport meta tag for mobile screens

## 🚀 Getting Started

No build tools or dependencies needed. It's plain HTML and CSS.

```bash
# 1. Clone the repository
git clone https://github.com/<your-username>/<your-repo>.git

# 2. Move into the project folder
cd <your-repo>

# 3. Open the dashboard in your browser
open index.html        # macOS
start index.html       # Windows
xdg-open index.html    # Linux
```

You can also use the **Live Server** extension in VS Code for auto-reload while editing.

## 🤝 Contributing (Team Guidelines)

1. Create your own branch: `git checkout -b feature/your-section`
2. Write your **Team Voices** article using the exact markup of the demo in `index.html` (see the comment block there).
3. Follow the article styles in `styles/dashboard.css` (lines 170–214).
4. If you add new CSS ids or classes, put them in `dashboard.css` **without breaking the main structure**, and tell the group.
5. Commit with a clear message and open a Pull Request.
